# QRFlow

> مولد أكواد QR مجاني وسريع باللغة العربية

QRFlow هو تطبيق ويب احترافي لإنشاء أكواد QR مخصصة باللغة العربية. تم بناؤه باستخدام React + Vite، ويعمل بالكامل محليًا داخل المتصفح دون الحاجة إلى خوادم خارجية.

## ✨ المميزات

- **12 نوع محتوى**: روابط، نصوص، WiFi، vCard، بريد، هاتف، SMS، واتساب، YouTube، فيديو، خرائط Google، PDF
- **تخصيص كامل**: ألوان، أشكال نقاط، أشكال زوايا، حجم، هامش
- **شعار مخصص**: رفع شعار خاص مع التحكم في الحجم
- **نص سفلي**: إضافة نص أسفل الكود بخطوط مختلفة
- **إطارات**: 3 أنواع إطارات قابلة للتخصيص
- **صيغ تحميل متعددة**: PNG، SVG، JPEG، PDF
- **دعم كامل للعربية**: UTF-8 + Byte mode لضمان قراءة النصوص العربية
- **خصوصية تامة**: كل شيء يتم محليًا في المتصفح - لا رفع للبيانات
- **تصميم متجاوب**: يعمل على الهواتف والتابلت والكمبيوتر
- **جاهز للنشر**: مبني بـ Vite، سريع وخفيف

## 🚀 التشغيل محليًا

### المتطلبات
- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn أو pnpm

### الخطوات

```bash
# 1. استنساخ المشروع أو تنزيل الملفات
cd qrflow

# 2. تثبيت الاعتمادات
npm install

# 3. تشغيل خادم التطوير
npm run dev
```

سيتم فتح التطبيق تلقائيًا على: `http://localhost:3000`

## 🏗️ البناء للإنتاج

```bash
npm run build
```

سيتم إنشاء ملفات الإنتاج في مجلد `dist/`.

### معاينة البناء محليًا

```bash
npm run preview
```

## ☁️ النشر

### النشر على Vercel

1. قم برفع المشروع إلى GitHub / GitLab / Bitbucket
2. افتح [Vercel](https://vercel.com) وقم باستيراد المشروع
3. اترك الإعدادات الافتراضية (Vite يكتشف تلقائيًا)
4. انقر Deploy

أو باستخدام Vercel CLI:

```bash
npm i -g vercel
vercel
```

### النشر على Netlify

1. قم برفع المشروع إلى GitHub
2. افتح [Netlify](https://netlify.com) وقم باستيراد المشروع
3. إعدادات البناء:
   - Build command: `npm run build`
   - Publish directory: `dist`
4. انقر Deploy

أو باستخدام Netlify CLI:

```bash
npm i -g netlify-cli
netlify build
netlify deploy --prod
```

## 🎨 التخصيص

### تغيير الألوان

افتح ملف `src/styles/global.css` وعدل المتغيرات في قسم `:root`:

```css
:root {
  --bg-primary: #202024;      /* الخلفية الرئيسية */
  --bg-card: #2A2A2F;         /* خلفية البطاقات */
  --accent-primary: #C47046;  /* اللون الرئيسي */
  --accent-secondary: #7BA8B8;/* اللون الثانوي */
  --text-primary: #E8E5DF;    /* لون النصوص */
  --text-secondary: #9A978F;  /* النصوص الثانوية */
}
```

### تغيير البريد الإلكتروني

ابحث عن `hello@qrflow.app` في الملفات التالية واستبدله:
- `src/pages/Contact.jsx`
- `src/pages/Privacy.jsx`
- `src/pages/Terms.jsx`
- `src/components/Footer.jsx`

### تغيير الرابط الأساسي

افتح ملف `index.html` واستبدل جميع حالات `https://qrflow.app/` بالرابط الجديد.

قم أيضًا بتحديث:
- `public/robots.txt`
- `public/sitemap.xml`

### تغيير عنوان الموقع والوصف

افتح ملف `index.html` وعدل وسوم الـ meta:
- `<title>` - عنوان الصفحة
- `<meta name="description">` - الوصف
- `<meta name="keywords">` - الكلمات المفتاحية
- Open Graph و Twitter Card tags

## 📝 ملاحظات تقنية

- **المعالجة المحلية**: يتم توليد جميع أكواد QR في المتصفح باستخدام مكتبة `qrcode`
- **دعم العربية**: يتم استخدام UTF-8 بشكل افتراضي، وتتعامل المكتبة مع النصوص العربية في Byte mode
- **الحد الأقصى للمحتوى**: يعتمد على مستوى تصحيح الأخطاء (L: 4296, M: 3391, Q: 2420, H: 1852 بايت)
- **الشعارات**: يُنصح باستخدام مستوى تصحيح أخطاء Q أو H عند إضافة شعار
